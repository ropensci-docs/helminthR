# Load the helminth interaction data

Load the helminth interaction data

## Usage

``` r
loadData(outdir = ".")
```

## Arguments

- outdir:

  output directory (default is the top-level of the package repo)

## Value

data.frame of host-helminth interactions

## References

Gibson, D. I., Bray, R. A., & Harris, E. A. (Compilers) (2005).
Host-Parasite Database of the Natural History Museum, London.
